# Архив прежнего рыболовного сценария

Здесь сохранены исходники, старые проверки и генераторы прежнего полного промыслового цикла. Они исключены из действующего runtime после перехода на два стационарных рабочих места 2026-11-10. Это постоянный архив исходников, а не текущая реализация и не набор проверок новой концепции.

Оригинальные бинарные пакеты удалённых карт и Blueprint находятся в Saved/Backups/StationaryWorkstations; перечень — Saved/Verification/StationaryWorkstations/RetiredAssets.json. SourceBeforeCleanup содержит копии смешанных файлов до удаления из них старых контейнеров, морозильника и зависимостей лебёдки от трала. README_BeforeStationary.md сохраняет предыдущую документацию.

Код перемещения игрока и судна остаётся в основном Source с выключенными флагами; код движения старых косяков сохранён в этом архиве.
