## Что реализовано

| Слой | Ответственность |
|---|---|
| `AMiniGameScenario`, `UMiniGameDefinition`, `UMiniGameStateTreeComponent` | Жизненный цикл, отдельный RunId и копия настроек запуска, задачи, события, результат, повтор/прерывание |
| `UXRInteractorComponent`, `IMiniGameInteractable` | Один владелец Grab/Release/Use, назначаемые Input Actions и руки, выбор цели, подробная диагностика |
| Общие компоненты кнопки, захвата, рычага и приёмника | Независимые объёмы, проверка контекста, привязка к руке, нейтраль/разгон, приём при отпускании |
| `AGrabbableItem`, `AMiniGameStation` | Базовые предметы/станции с назначаемыми визуальными компонентами, восстановление предмета |
| Общий UMG-виджет, стиль и Display Component | Данные представления, сообщения, метрики, цвета и оформление через ассеты |
| `UFishingDefinition`, определения видов | Баланс лебёдки/ленты/обработки/очков, состав партии, классы рыбы и ножа, сообщения и привязки операций |
| Механики Winch, Conveyor, Processing | Работа сети, нагрузка и остановка; подача/сортировка/возврат; обработка/сдача |
| `AFishingMiniGameScenario`, `AFishingFish` | Специальные правила рыбалки и состояние рыбы |
| Модуль `YakutSimulatorEditor` | Создание недостающих примеров ассетов и автотесты; не входит в runtime-игру |

Порядок этапов хранится в `ST_Fishing_Default`. Задания, разрешённые действия, рабочие места и тексты задаются профилем. Идентификаторы задач/действий/мест — FName; события StateTree — Gameplay Tags. Runtime-прогресс не записывается в исходные Data Assets.

В общих runtime-классах отсутствуют зависимости от рыболовных типов и пути Content. Меши, материалы, масштабы и шрифты не подменяются нативной логикой. Unreal-примитивы назначены в примерных Blueprint. Коллизии, pivot/ось рычага, ToolTip ножа, CutPath и anchors редактируются независимо от декоративных мешей.

Новый `BP_MiniGamePawn` использует проверенный XRFramework. Шесть прежних обработчиков игровых действий удалены из его копии; ввод принадлежит общему interactor. Исходные Blueprint XRFramework сохранены. Защита от соседнего СТОП проверена по записанным ранее положениям контроллеров.

## Проверки

Сводные результаты: `YakutSimulator/Saved/ArchitectureMigration/automation-results.json`. Полный прогон сохранённого уровня — около 85 секунд на стандартных скоростях. Тест использует обычные тики мира и синтетические положения рук; он проходит восемь рыб через захват, лотки, обработку и сдачу, затем начинает новую смену.

| Тест `Yakut.MiniGames` | Проверяемое поведение |
|---|---|
| `Common.CustomStateTree` | Промежуточная задача с таймером, переходы из данных, отказ при отсутствующем ID задания |
| `Common.DesignerDataValidation` | Некорректный размер партии, дубли ID, отсутствие меша, неправильный ход рычага |
| `Common.LifecycleAndIsolation` | Копия настроек, один активный сценарий, новый RunId, отклонение позднего события, прерывание |
| `Common.InputAndDiagnostics` | Шесть привязок без дублей, одно действие при удержании, выбор кнопки, журнал событий |
| `Common.LeverAndVisualPreservation` | Захват/следование, нейтраль, разгон, вторая рука, восстановление transform/материала/меша |
| `Common.GrabRecoveryAndOwnership` | Общий предмет без рыбалки, отпускание, физика/возврат, потеря tracking, предмет старого запуска |
| `Fishing.SafetyButtonsAndOverload` | Инструктаж, соседний СТОП, задержка перегрузки, сброс, контекстная подсказка рычага |
| `Fishing.SortingRecoveryAndThirdSpecies` | Ошибки/пропуски, повторная сортировка, три вида, другой меш/путь обработки, отключённые перегрузки, сохранение настройки физики отпускания |
| `Fishing.CompleteShiftAndRestart` | Партия, обработка двумя руками по точкам, восстановление готовой рыбы, сдача/очки/повтор |
| `Fishing.SavedLevelPlaythrough` | Полная сохранённая карта, единственный владелец ввода, компенсация HMD-смещения, восемь рыб и повтор |

Обычная Editor-сборка и Game-сборка Win64 Development успешны. Ассеты приготовлены и Windows-пакет создан. Собранная игра запускается вне редактора, загружает новый уровень/StateTree/UMG и подключает обе руки в Meta XR Simulator 69.

В обычной DX12-конфигурации на этой машине обнаружены ошибки спекулятивного создания PSO. Диагностический запуск с `r.PSOPrecaching=0` проходит без этих ошибок; этот обход добавлен только для `-Simulator -Packaged`. Система OpenXR и настройки обычного аппаратного запуска не изменены. Отключение предварительного кеширования может дать задержку при первом появлении материала; производительность на физическом шлеме пока не измерена.

Во время переноса исправлены найденные тестами ошибки тестового стенда и отказа сценария при неверном задании StateTree. Последние результаты отдельных тестов обновляются после соответствующих исправлений; отчёт фиксирует происхождение прогонов. Визуально проверены вывод кириллицы, tracking и контекстные панели. Текст рычага не дублирует инструктаж и не предлагает Grip до начала работы лебёдки.

## Запуск и сохранённый исходник

- Editor: `Start-YakutSimulator.ps1`.
- Editor с проверенным симулятором: `Start-YakutSimulator.ps1 -Simulator`.
- Собранная версия: `Start-YakutSimulator.ps1 -Packaged`.
- Собранная версия с симулятором: `Start-YakutSimulator.ps1 -Simulator -Packaged`.

Стартовую карту выбирают Project Settings → Maps & Modes. Launcher не подменяет её рыболовным путём. Для Rider открывайте `YakutSimulator/YakutSimulator.uproject`.

Резервная копия исходной версии: `YakutSimulator/Saved/ArchitectureMigration/Baseline-20261107-195641`. Старые классы, карта и генераторы выведены из рабочей Source/Content и сохранены в архиве миграции. Одноразовый перенос уровня завершён; рабочие исходники не используют его `scene.json` или файлы Saved. Оставлены только готовые шрифтовые ассеты, на которые ссылаются сохранённые статические подписи исходной сцены.

## Что остаётся дизайнеру и проверке на устройстве

Финальные модели, материалы и декорации заменяют примитивы через Blueprint/Editor. После замены проверяются объёмы, рабочие точки и траектории. На целевом VR-комплекте нужно отдельно проверить калибровку, досягаемость, читаемость UI, комфорт переходов и стабильность кадров. Симулятор и синтетические руки не подтверждают эти параметры.
