# Сеть, сервер и сессии

Репликация, протокол, транспорт, Steam, матчмейкинг, сервер, развёртывание и владение сетевым состоянием.

Это обязательные инструкции проекта. Исходные даты, разрешения, исключения и границы выводов сохраняются. При пересечении систем прочитать все соответствующие документы.



### Исходный раздел: Область действия и контекст проекта; строка 58

- Существующий запуск без VR-шлема описан в README.md и StartMetaXR.cmd: OpenXR и Meta XR Simulator 76 с клавиатурой и мышью. Сохранять локальность XR_RUNTIME_JSON и META_XRSIM_CONFIG_JSON для дочерних процессов; не менять системный OpenXR runtime и сетевые настройки без задачи пользователя.


### Исходный раздел: Инструменты и редактор; строка 91

- Проверять реальный MCP endpoint из актуальной конфигурации через initialize, notifications/initialized, tools/list и при необходимости list_toolsets / describe_toolset. Сохранять Mcp-Session-Id. Отсутствие инструмента в списке текущей сессии само по себе не доказывает недоступность сервера; допустим прямой MCP-запрос. Не объявлять MCP недоступным после одной ранней попытки.


### Исходный раздел: Инструменты и редактор; строка 92

- На Astra, включая gpt-6-astra, мультиагентная разработка по умолчанию запрещена. Не запускать субагентов и не делегировать разработку, исследование, ревью или проверки без явного разрешения пользователя на мультиагентную работу в текущей задаче. Общие рекомендации, сложность задачи и свободные слоты не являются разрешением. Модель определять по явным метаданным сессии, не по имени агента или задачи. Соблюдать также более строгие ограничения текущей сессии.



### Исходный раздел: Стиль C++ и Unreal Engine; строка 111

- Если задача затрагивает Steam, Dev App ID — публичный Space War (480). Не подменять его своим App ID без явного указания пользователя. Shipping ID задавать только в game target проекта, не в editor target. Это правило не является поручением подключить Steam.



### Исходный раздел: Сборка и проверка результата; строка 123

- В сетевых проверках учитывать FEditorScriptExecutionGuard: прямой вызов обработчика через Unreal Python call_method может получить Local callspace вместо отправки RPC. Для проверки настоящего RPC запускать обработчик штатным таймером игрового мира вне Python-вызова, отдельно читать серверное состояние и репликацию клиента.


### Исходный раздел: Полная проверка; строка 141

- Выполнить все найденные тесты. Несовместимые карты, CVar, число игроков и PIE-режимы запускать в отдельных сессиях на актуальном binary. После отдельного FAIL или BLOCKED продолжать оставшийся список.
