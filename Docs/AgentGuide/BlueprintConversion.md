# Blueprint и генерация C++

Анализ графов, K2/Kismet, экспорт, генерация и контракты преобразования Blueprint; читать при изменении конвертера.

Это обязательные инструкции проекта. Исходные даты, разрешения, исключения и границы выводов сохраняются. При пересечении систем прочитать все соответствующие документы.



### Исходный раздел: Стиль C++ и Unreal Engine; строка 109

- Основа отладочного вывода — Print String, UKismetSystemLibrary::PrintString. Debug-хелперы именовать {Entity}Debug; общие заголовки размещать в Public, реализации — в Private.
